# Upgrade Timers (Stub)

We model upgrades as:
- Each mastery level requires **4 fragments**
- Once fragments are purchased, you can start an upgrade timer
- Time grows exponentially-ish:
  L2: 1d, L3: 2d, L4: 5d, L5: 10d, ...

In offline beta we keep this as **data only**.
When backend is added, these timers must be server-authoritative.
